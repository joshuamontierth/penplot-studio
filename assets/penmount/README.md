# Pen mount parts

From the "Modular System For A1, P1, & X1 Series" pen mount by Falu Mendy Vergara
([MakerWorld 2029113](https://makerworld.com/en/models/2029113-modular-system-for-a1-p1-x1-series)), included for
the owner's personal use. Check the model's license on MakerWorld before sharing this repository or its builds.

| File | Part | In the app |
|---|---|---|
| `pen-cartridge.stl` | Pen cartridge | pen bore resized for the measured pen |
| `spring.stl` | Spring | ring bores resized for the measured pen |
| `attachment-x1p1.stl` | Attachment for X1 / P1 | saved unchanged |
| `attachment-a1.stl` | Attachment for A1 | saved unchanged |
